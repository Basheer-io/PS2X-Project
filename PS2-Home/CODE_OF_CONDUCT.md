# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). By participating, you agree to uphold it.

In short: be kind, be constructive, no harassment or discrimination. Maintainers may remove comments, issues or PRs, and ban participants, who violate it.

Project-specific rule: requests for, or sharing of, pirated games or BIOS files are not allowed.

Report problems to the maintainers via the contact listed in SECURITY.md (replace with a real address before publishing).
